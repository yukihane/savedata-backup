# savedata-backup

Windows ゲームのセーブデータの保存先候補を探し、選んだフォルダーやファイルを tar アーカイブにまとめるコマンドラインツールです。

## このプログラムを使うモチベーション

OS のクリーンインストールなどに備えてゲームのセーブデータをバックアップしようとしても、保存先はゲームごとに異なります。ゲームが多いほど、一つずつ保存先を調べてコピーする作業に手間がかかり、OS の入れ直しをためらう原因にもなります。

このプログラムは、保存先の候補をまとめて探し、複数のゲームのデータを一度にバックアップできるようにすることで、その手間を減らします。

多少不要なデータを含んだままでも、候補のフォルダーをまとめてバックアップできます。対象を厳密に絞り込む作業を減らし、手早くバックアップを作ることを重視しています。一度作った対象一覧は、次回以降も使えます。

### Ludusavi との使い分け

[Ludusavi](https://github.com/mtkennerly/ludusavi) を試したところ、手元にある日本の小規模な同人ゲームなどでは、保存先を手動で設定する必要がありました。ゲームが多いと、一つずつ保存先を調べて登録する作業が煩雑になります。

Ludusavi は、ゲームごとの保存先情報や個別の設定に基づいてバックアップ・復元できることが強みです。対象を正確に指定してバックアップしたい場合は、Ludusavi が適しています。

ただし、手動設定が必要なゲームでは、「このゲームもバックアップしておきたい」と思い出せなければ、設定されないままバックアップから漏れる可能性があります。OS を入れ直す前に、遊んだゲームをすべて思い出して確認するのも手間のかかる作業です。

savedata-backup は、指定した範囲から保存先らしいフォルダーを探し、まとめてバックアップします。そのため、ゲームの存在を忘れていても、検索条件に合う保存先があればバックアップ対象に含まれる可能性があります。多少不要なデータが混ざっても、個々のゲームを洗い出す手間を減らして退避したい、という考え方のツールです。ただし、検索条件に合わない保存先は見つからないため、すべてのセーブデータを保存できる保証はありません。

## できること

- セーブデータの保存先候補を探す
- バックアップ対象フォルダーの容量を確認する
- 選んだフォルダーやファイルを、1つの tar アーカイブにまとめる

検索結果は保存先の候補であり、すべてのゲームのセーブデータが見つかるとは限りません。必要な保存先が含まれているかを確認し、見つからなかったものは対象一覧に追加してください。検索の仕組みと対象の追加方法は、以下の例で説明します。

## 事前準備

Windows 上の任意のフォルダーに `savedata-backup.exe` を置きます。エクスプローラーでそのフォルダーを開き、その場所で PowerShell を開いてください。以降のコマンドは、この PowerShell で実行します。

バックアップファイルはコマンドを実行したフォルダーに作成されるため、十分な空き容量を用意してください。

## 使用例：2つのゲームのセーブデータをバックアップする

以下では、候補を確認し、検索で見つからなかったファイルを追加してバックアップする流れを説明します。`D:\Games` に次のファイルがあるものとします。

```text
D:\Games
├─ AdventureGame
│  ├─ AdventureGame.exe
│  └─ Save
│     ├─ slot1.dat
│     └─ slot2.dat
├─ PuzzleGame
│  ├─ PuzzleGame.exe
│  └─ progress.dat
└─ SaveEditor
   └─ SaveEditor.exe
```

バックアップしたいのは、次の2つです。

- `AdventureGame` の `Save` フォルダー全体
- `PuzzleGame` の `progress.dat` ファイル

`SaveEditor` はセーブデータを編集する別のツールなので、この例ではバックアップ対象から外します。

### 1. 初期設定を作成する

引数を付けずに実行します。

```powershell
.\savedata-backup.exe
```

設定フォルダーがなければ作成されます。また、`search_dir.txt` がなければ、ドキュメントフォルダーのパスを記載したファイルが作成されます。**すでに `search_dir.txt` がある場合、その内容は変更されません。**

実行すると `search_dir.txt` の場所が表示されます。設定フォルダーを開くには、エクスプローラーのアドレスバーに次のパスを入力してください。

```text
%APPDATA%\yukihane\savedata-backup\config
```

`target_dir.txt` と `target_file.txt` は、後の手順で `search` コマンドを実行したときに作成されます。

### 2. ゲームを探す場所を指定する

設定フォルダーにある `search_dir.txt` をテキストエディターで開き、この例では内容を次のように置き換えます。

```text
D:\Games
```

これは「`D:\Games` と、その中のフォルダーからセーブデータを探す」という指定です。複数の場所を探す場合は、1行に1つずつフォルダーのパスを記述します。

### 3. 保存先の候補を探す

```powershell
.\savedata-backup.exe search
```

このプログラムは、大文字・小文字を区別せず、名前に `sav` を含むファイルやフォルダーを探します。この例では、設定フォルダーの `target_dir.txt` に次の候補が書き込まれます。

```text
D:\Games\AdventureGame\Save
D:\Games\SaveEditor
```

`AdventureGame` の `Save` フォルダーが見つかりました。一方、`SaveEditor` も名前に `sav` を含むため、候補に入っています。ファイル名に `sav` を含むファイルが見つかった場合は、その親フォルダーが候補になります。

`PuzzleGame` の `progress.dat` は名前に `sav` を含まないため、検索では見つかりません。このように、検索結果には不要なものが含まれたり、必要なものが抜けたりすることがあります。

**`search` を実行すると、既存の `target_dir.txt` は上書きされます。** `target_file.txt` は、存在しない場合に空のファイルとして作成されます。既存の内容は保持されます。

### 4. バックアップ対象を確認・調整する

`target_dir.txt` を開き、必要な保存先が候補に含まれているか確認します。候補のフォルダーはそのままバックアップ対象にできますが、容量を抑えたい場合などは不要なものを削除します。

この例では `SaveEditor` の行を削除し、次の内容だけを残します。

```text
D:\Games\AdventureGame\Save
```

ここに記述したフォルダーは、配下のファイルやサブフォルダーを含めてバックアップされます。この例では、`slot1.dat` と `slot2.dat` が両方バックアップ対象になります。

次に、設定フォルダーの `target_file.txt` を開き、検索で見つからなかったファイルを追加します。

```text
D:\Games\PuzzleGame\progress.dat
```

このように、フォルダー全体を保存する場合は `target_dir.txt`、特定のファイルだけを保存する場合は `target_file.txt` に記述します。検索で見つからなかったフォルダーも、`target_dir.txt` に直接追加できます。

### 5. 容量を確認する（任意）

バックアップに必要な空き容量の目安を知りたい場合や、大きなフォルダーを対象から外したい場合は、次のコマンドを実行します。

```powershell
.\savedata-backup.exe check
```

`target_dir.txt` に記述したフォルダーの容量が、大きい順に表示されます。各行は「容量（バイト）, パス」の形式です。例えば、次の表示は `Save` フォルダーの容量が約1 MiBであることを示します。

```text
1048576, D:\Games\AdventureGame\Save
```

容量の大きいフォルダーから内容を確認すると、必要に応じて対象を絞り込めます。容量を取得できないフォルダーは `none` と表示されます。パスが正しいか、その場所にアクセスできるかを確認してください。

`target_file.txt` に記述したファイルの容量は、この表示には含まれません。

### 6. バックアップを作成する

ゲームを終了してから、次のコマンドを実行します。

```powershell
.\savedata-backup.exe backup
```

コマンドを実行したフォルダーに `archive.tar` が作成されます。この例では、アーカイブに次のデータが入ります。

```text
D/Games/AdventureGame/Save/slot1.dat
D/Games/AdventureGame/Save/slot2.dat
D/Games/PuzzleGame/progress.dat
```

元のドライブ名は、アーカイブ内の先頭のフォルダー名として保存されます。

**既存の `archive.tar` は上書きされます。** 前回のバックアップを残したい場合は、実行前に名前を変更するか、別のフォルダーに移動してください。

### 次回も同じゲームをバックアップするには

設定した一覧は保存されているので、次回はゲームを終了し、次のコマンドだけを実行します。

```powershell
.\savedata-backup.exe backup
```

新しいゲームを追加した場合は、対象のパスを一覧に追加するか、`search` で探し直してください。検索をやり直すと `target_dir.txt` が上書きされるため、以前に手動で追加・削除した内容も確認してください。

## 設定ファイルの書き方

設定ファイルは次の3つです。

| ファイル | 記述する内容 |
| --- | --- |
| `search_dir.txt` | セーブデータを探すフォルダー |
| `target_dir.txt` | フォルダー全体をバックアップする対象 |
| `target_file.txt` | 個別にバックアップするファイル |

いずれも、1行に1つずつ、ドライブ名から始まる絶対パスを記述します。引用符やコメントは付けず、空行も入れないでください。対象がなければファイルの内容を空にします。

`%APPDATA%` などの環境変数は展開されません。例えば `C:\Users\Taro\AppData\Roaming\Game` のように、実際のパスを記述してください。

`target_file.txt` ではワイルドカードも使用できます。例えば、次の行は指定フォルダー内の `.sav` ファイルを対象にします。

```text
D:\Games\AnotherGame\*.sav
```

フォルダー単位ですでに選んだファイルは、`target_file.txt` に重複して記述する必要はありません。

## コマンド一覧

| コマンド | 動作 |
| --- | --- |
| 引数なし | 設定フォルダーと `search_dir.txt` を、存在しない場合に作成し、検索設定ファイルの場所を表示する |
| `search` | 保存先候補を検索し、`target_dir.txt` に書き出す |
| `check` | 対象フォルダーの容量を表示する |
| `backup` | 対象のフォルダーとファイルを `archive.tar` にまとめる |

このプログラムには自動復元機能はありません。復元する場合は tar アーカイブを展開し、必要なデータを元の保存先へ戻してください。
