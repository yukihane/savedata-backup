== これは何？

Windows ゲームのセーブデータをバックアップする際に役立つツールです。
次の機能を有しています。

* セーブデータの場所を探し、一覧出力する
* 一覧を元にtarアーカイブを作成する

== 使い方

. 本プログラムを引数無しで実行します。
    * `%APPDATA%\yukihane\savedata-backup\config` に(無ければ) `search_dir.txt` というファイルが作成されます。
. `search_dir.txt` に、セーブデータを探すディレクトリを記述します。
    * 1行に1ディレクトリを記述します。
    * 例: `D:\mygames`
. 本プログラムを引数 `search` を伴い実行します。
    * configディレクトリに `target_dir.txt`, `target_file.txt` という2ファイルが作成されます。
    * `target_dir.txt` は、既に存在した場合上書きされます。
. `target_dir.txt` を編集し、アーカイブ対象のディレクトリのみを残します。
. `target_file.txt` には、ディレクトリ単位でなくファイル単位でアーカイブするものを記述します。
    * 1行に1ファイルを記述します。
    * 例: `E:\mygames\game1\save.dat`
. 本プログラムを引数 `backup` を伴い実行します。
    * カレントディレクトリに `archive.tar` というファイルが作成されます。

== 実行ファイルから保存先の手掛かりを探す

`savedata-backup inspect "D:\\Games\\Game\\Game.exe"` を実行すると、実行ファイル内の UTF-8 / UTF-16LE 文字列から、保存先らしいパスを表示します。
保存処理が DLL にあるゲームでは、その DLL も同じコマンドで調べられます。
1ファイルあたり 512 MiB まで調べられます。
`%APPDATA%` などの環境変数で始まるパスは展開し、現在その場所が存在するかも表示します。
相対パスは実行ファイルのあるディレクトリを基準にした参考値です。

表示されたパスを確認し、必要なディレクトリやファイルを `target_dir.txt` / `target_file.txt` に追加してください。
`inspect` はこれらの設定ファイルを書き換えません。

この調査は文字列の静的な検索です。プログラムが実行時にパスを組み立てる場合や、DLL・スクリプト側に保存処理がある場合は見つかりません。
また、表示されたパスが存在しても、そこにセーブデータを書いている証拠にはなりません。
設定ファイル、ログ、キャッシュなどもゲームは読み書きします。
保存先を確定するには、ゲームで実際にセーブする間のファイル書き込みを監視して確認してください。

== 動機

バックアップしようと考えたとき、バックアップ対象として優先度が高いにもかかわらずどこにあるのかわからないデータとして、ゲームのセーブデータがあります。

本プログラムは、そのようなデータを見つける手間を省き、効率的にバックアップ作業を行う助けになることを目的としています。
